## CSVで手直ししたところ
- 列名は `日付`・`視聴回数`（手順メモの `views` ではない）
- 2行目に「合計」行（36,577）がある → `df[df["日付"] != "合計"]` で除いてから日付に変換する
  - `parse_dates=["日付"]` を最初に付けると「合計」が日付にならず、文字列のまま残る
- 視聴0回の日（7/14・7/16）は行がない → 「7日」ではなく「7行」の平均になる（SQLの `ROWS` と同じ）

## SQL と pandas の違い（最初の6日）
| 書き方 | 7/15〜7/21 の値 |
|---|---|
| SQL `AVG() OVER (ORDER BY 日付 ROWS BETWEEN 6 PRECEDING AND CURRENT ROW)` | ある行だけで平均が出る（4.0, 5.5, 6.33, 19.0 …） |
| pandas `rolling(window=7).mean()` | 空（NaN）。7行そろった 7/22 から 31.57 |
| pandas `rolling(window=7, min_periods=1).mean()` | SQL と同じ（4.0, 5.5, 6.33 …） |

7/22 以降はどの書き方でも同じ値。

## 追加：Shorts と長尺の比較（ノートブックの4・5セル目）
データ：YouTube Studio の動画別 CSV（リポジトリには入れていない）

| 項目 | pandas | SQL（v_video）／note 1本目 |
|---|---|---|
| 本数・合計 | 342本・36,474回 | 342本・36,474回 |
| 本数（Shorts／長尺／Live） | 201／138／3 | 201／138／3 |
| 1本あたり Shorts | 157.4回 | 157.4回 |
| 1本あたり 長尺 | 32.4回 | 32.4回 |
| 長尺の公開月別（7→10月） | 72.2→31.4→20.9→4.5 | 72.2→31.4→20.9→4.5 |
| Shorts の公開月別（7→10月） | 79.7→147.5→169.8→178.2 | 79.7→…→178.2 |

CSVで手直ししたところ
- 視聴回数が空欄の動画が9本ある → `fillna(0)`（SQL の `ISNULL(…, 0)` と同じ）。これをしないと本数が 195／135 になり、1本あたりが 162.3／33.1 とずれる
- 分け方は SQL と同じ：長さ0 または タイトルに LIVE → Live、60秒以下 → Shorts、それ以外 → 長尺
- 公開日が空欄の Shorts が5本ある → 公開月別の表には入らない（SQL の公開月別も同じ）
- グラフの日本語は Colab で文字化けする（□になる）→ 列名・軸名を英語にした（Shorts／Long、Publish month）

グラフ：`images/py_02_shorts_vs_long.png`（公開月ごとの1本あたり視聴回数の棒グラフ）
