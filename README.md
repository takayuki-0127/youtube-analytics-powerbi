# YouTube チャンネル分析（SQL Server × Power BI × pandas）

- 目的：自分で運営している睡眠用BGMチャンネルの YouTube Studio データ（2026/7/14〜10/14、動画342本）を分析し、どの動画がどう見られているかを調べた
- 使った技術：SQL Server（ビュー・ウィンドウ関数 `AVG() OVER`／`RANK()`）、Power Query、DAX、Power BI、pandas（Google Colab）
- 答え合わせ：同じ数字を3つの道具で出して一致を確認した（日別 91日・36,577回、10/14 の7日移動平均 602.29、1本あたり Shorts 157.4回／長尺 32.4回、公開7日間の上位5本）
- 仮説：「Shorts は入口、長尺は本体」。Shorts は公開当日に1本あたり約680回見られてすぐ止まり、長尺は2日目以降に少しずつ伸びる
- データの差：日別の合計（36,577回）と動画別の合計（36,474回）は103回（1日約1回・全体の0.3%）違う。期間中に削除した動画の分と判断し、全体の推移は日別、動画・種類別の比較は動画一覧と使い分けた
- フォルダ：`sql/`（整形ビュー・クエリ3本・上位5本の RANK クエリ）、`python/`（pandas で再現したノートブック）、`docs/`（SQL・Power BI・pandas の答え合わせと、SQL と pandas の対応表）、`images/`（Power BI と pandas の画面）
- 元の CSV は入れていない
